# 关于创建GithubPages
## 为什么选择GithubPages?
优点
1. 不需要管域名与TLS
2. 部署流水线实现变更轻松
3. 无花费

缺点
1. 容量有上线
2. 访问速度略微慢
3. 支持静态网页更方便

对于个人博客或知识分享，如果是静态网页，或需要频繁更新博客内容，使用它可能是个不错的选择
这里主要讲一下优点
## 优点
### 不需要管域名与TLS
1. 完整报备域名，能够使用TLS
2. 未报备域名，使用cloudflare时开TLS可能会被拦截，不使用则不影响,但一般会提示'不安全'，而域名一般需要购买，免费的需要定时更换，比较麻烦
3. 无域名，通过IP地址来访问并不优雅与安全

github.io可提供二级域名直接使用，十分便利


github在境内通常是可以直连访问的，不同地区可能访问速度有所差异，或许会较于其他网站偏慢，如果是强功能性网站，直接备案并使用云服务器会方便很多
### 变更轻松
使用Github自带的Action，实现commit即变更，而个人服务器，可能需要在本地构建出dist后，需要登入个人服务器并覆盖之前的dist，而后者可能需要输入密码，切换到对应文件夹等，麻烦很多

### 开销层面
无具体开销

## 创建方式
1. 在根目录创建.github/workflows/deploy.yml进行配置网站构建的指令
2. 启用工作流
    - 去仓库 Settings → Pages
    - Source 下拉菜单 → 改为 Deploy from a branch
    - Branch 选 gh-pays → / (root) → Save
3. Commit
