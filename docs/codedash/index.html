核心功能

CodeDash 提供全方位 AI 编码能力，从代码编辑到浏览器自动化，一应俱全。

自研 Agent 引擎

零框架依赖，完全自研的 agent-core 引擎。支持 think→act→stream 循环，Plan、Agent、Chain 三种工作模式。

agent-core

深度代码理解

基于 tree-sitter 的代码解析、bge-small-zh 语义嵌入、BM25 + 向量搜索双层召回。支持本地离线语义索引，无需联网。

code-search

浏览器自动化

内置 headless Chromium 控制器，支持 12+ 浏览器操作工具：导航、点击、输入、滚动、截图、文件上传等，AI 可像人类一样操作网页。

12+ 工具

计算机控制

基于 @nut-tree/nut-js，AI 可直接控制鼠标、键盘、屏幕截图。实现真正的桌面自动化操作。

computer-use

双进程架构

Electron 前端 + agent-core 后端通过 JSON-RPC 2.0 over stdio 双向通信，一方崩溃不影响另一方，架构优雅解耦。

架构设计

三层记忆系统

TaskLayer（任务摘要）+ TurnLayer（轮次向量索引）+ Recall（BM25+向量RRF融合排序），AI 可记住长期上下文。

memory

自动化调度

4 种触发模式：一次性、每日、每周、自定义间隔。定时执行 AI 任务。

automation

离线语音识别

集成 Vosk 引擎，支持离线语音转文字。无需云服务，保护隐私。

speech

工作流编排

内置 Workflow 引擎，支持 并行、串行、Pipeline、Loop 四种执行模式，复杂任务一键编排。

workflow

自研 Agent 引擎

三种工作模式

根据任务需求灵活选择，从安全只读到全权执行，再到自动化队列。

Plan 模式

AI 仅使用只读工具探索，生成详细的 .plan.md 文件。用户确认后再切换 Agent 执行。

只读安全

Agent 模式

AI 拥有完整权限，可读写文件、执行 Shell 命令、控制浏览器和计算机。

全权限

Chain 模式

多任务自动队列。Plan → Agent → Plan → Agent 自动循环，直到队列清空。

自动队列
