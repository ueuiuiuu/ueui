v0.2.0 — 2026-10-04

v0.2.0 新增 macOS 版本

主要更新

  1. macOS 版本发布 — 正式支持 Apple Silicon（M 系列）与 Intel 芯片，提供 .dmg 安装包，与 Windows 版功能完全一致
  2. 不再依赖系统 Node.js — Agent 引擎改用应用内置运行时启动，用户机器上无需预装 Node.js 即可使用全部 AI 能力
  3. Agent 引擎随包分发 — agent-core 及其全部原生依赖（代码解析、向量检索、嵌入式数据库、终端）一起打包，安装后开箱可用
  4. 安装包体积优化 — 剔除与当前平台无关的预编译产物，安装包体积减少约 40%

说明

  1. macOS 安装包未使用 Apple 开发者证书签名（ad-hoc 签名），首次打开需要在「系统设置 → 隐私与安全性」中点击「仍要打开」放行一次，详见 文档 · macOS 首次打开
  2. Windows 版本次未改动，仍为 v0.1.0，可继续从该版本下载
  3. macOS 版语音转文字依赖的 ffi-napi 在 Apple Silicon 上暂无预编译产物，该功能会自动不可用，不影响其余功能

v0.1.0 — 2026-07-27

v0.1.0 首次发布

主要更新

  1. 界面美化 — 整体 UI 重新设计，亮色/暗色双模式，视觉风格更加现代统一
  2. 语音识别 — 集成 Vosk 离线语音引擎，支持离线语音转文字，无需云服务，保护隐私
  3. 工具增强 — 新增 Workflow 工作流引擎（支持并行/串行/Pipeline/Loop 四种执行模式）；引入工具权限系统 (RBAC)，精细控制 AI 可调用的工具范围
  4. ComputerUse 与浏览器工具 — 基于 nut.js 的桌面自动化，AI 可直接控制鼠标键盘；内置 headless Chromium，支持 12+ 浏览器操作工具
  5. 提示词增强与覆盖 — 增强系统提示词效果，支持用户自定义提示词覆盖默认行为
  6. 通知功能 — 任务完成、异常等关键节点系统通知
  7. 交互优化 — 工具默认收缩与展开、历史提问小窗、会话页面移至右侧而非居中、历史提问分页
  8. Fork / Git 功能 — 内置 Git 操作与项目 Fork 能力

细节更新

  1. 左侧文件夹默认不打开，且增加记忆（记住用户折叠/展开偏好）
  2. 右键菜单"资源管理器/终端打开"位置上移，更方便触达
  3. 修复 EditFile 写长文本容易出错的问题
  4. 任意位置右键弹出对话处理窗口，快速发起 AI 交互
  5. 输入框内容复制优化；输出内容复制按钮位置优化；输入框退出后重新进入保留之前输入内容
  6. 文件夹内 Ctrl+F 搜索支持
  7. 工具调用默认不展开，减少视觉干扰
  8. 添加 CodeDash 品牌图标
  9. 实现并发能力，多任务可并行执行
  10. 添加插件模块，支持扩展自定义功能
  11. 针对 DeepSeek 优化缓存策略，提升响应速度
  12. 添加英语模式，界面国际化
  13. 添加 Debug 模式，便于开发者调试
