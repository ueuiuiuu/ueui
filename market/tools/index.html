01 JavaGUI · Windows

QuickRecorder-4

已经连续用了一年多的时间记录器。不用打开表格，也不用手写编号—— 敲一行，它自己判断这是早上还是晚上，然后把标签、时长、序号都补齐。

  • 自动判断时间段，自增任务序号，编号不用自己记
  • 标签化记录，同一件事的记录自动归到一起
  • 可视化总结：热力图、饼状图，看时间花在哪
  • 格式化日志，随时导出一份可读的复盘
仅支持 Windows · 长期自用

02 Python · LangChain

KnowingAI

可以当成个人 AI 知识库，但它更专一：把散落的笔记切成一道一道题， 用来复习，而不是用来搜索。笔记写完的那一刻，题库就已经在长了。

  • 笔记转题库，复习时只看题，不重读长文
  • AI 题解与基于题库的问答，答错能追问
  • 刷题热力图与多级收藏，进度看得见
  • 智能抽题、本地桌面运行，明暗模式都支持
本地桌面 · 需要自备 Key

04 Skill · Open

CodeBridge
Skill

在 C++、Java、Python 里，同一类算法的骨架其实是同一套。 这个 Skill 做的事，是把那套骨架拆成组件——换语言时，换组件，而不是重写一遍。

  • 抽象通用算法逻辑：输入层、算法核、输出层分开
  • 组件化转换，改“组件”而不是改全文
  • 覆盖 C++ / Java / Python 的常见写法差异
  • 作为一个可复用的 Skill 安装，随 Agent 一起跑

Exporter

Agent
Dissector

  • req → resp 全链路追踪，不跳步
  • 任务队列与调度：并发、重试、取消落在哪
  • 消息持久化与上下文压缩的真实策略
  • 工具调用模型：schema、校验与回填
