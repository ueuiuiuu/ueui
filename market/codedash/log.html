LATESTv0.2.12026-10-10

v0.2.1 — macOS 修复版

这一版集中修复 v0.2.0 在 macOS 上暴露的四个问题，建议 macOS 用户升级。从 v0.2.0 升级无需卸载，直接用新包替换「应用程序」里的 CodeDash 即可。Windows 版当前仍为 v0.2.0。

修复

  1. 填完 API Key 不生效 — 在设置里填好 Base URL / API Key 后直接开始对话，会报 You didn't provide an API key，日志显示 Key: (empty)。原因是模型配置只写进了本地存储，没有推送给 Agent 引擎，必须重启应用才生效。现在保存后立即生效，新添加的模型也会马上出现在聊天面板的模型下拉里。
  2. 关掉窗口再打开会报错 — macOS 上关闭窗口不会退出应用，再点 Dock 图标重新打开时窗口起不来（Attempted to register a second handler）。原因是重建窗口时重复注册了内部通信通道。现在可以反复关闭、重开。
  3. 左上角图标显示成占位图 — 标题栏的 CodeDash 图标加载失败，显示为碎图。原因是图标用了绝对路径，打包后走 file:// 协议会解析到文件系统根目录，已改为相对路径。
  4. 数据被写进应用包内部 — 会话历史与代码索引原先写在 app 包里的 Contents/Resources/agent-core/dist 下，导致每次更新或重装应用都会丢失历史记录，且索引会持续撑大应用包。现已统一改到 ~/Library/Application Support/ 下。

说明

  1. 本次修复针对 macOS 版，尚未合入 Windows 构建；Windows 版当前为 v0.2.0。
  2. macOS 版语音转文字依赖的 ffi-napi 在 Apple Silicon 上暂无预编译产物，该功能会自动不可用，不影响其余功能。
FEATUREv0.2.02026-10-04

v0.2.0 — macOS 版本发布 · 学习模式上线

主要更新

  1. macOS 版本发布 — 正式支持 Apple Silicon（M 系列）与 Intel 芯片，提供 .dmg 安装包，与 Windows 版功能完全一致。
  2. 学习模式 — 全新的题库工作区：按文件夹组织题目，支持「会了 / 不会」练习、收藏与置顶、刷题统计与热力图；可以直接让右侧 AI 从资料里提取题目并一键保存到题库。
  3. 便携记录 — 待办、语录、统计与热力图一体的记录面板，Agent 可以通过工具直接读写记录。
  4. 一键生成学习周报 — 聚合学习时长与刷题记录生成 Markdown 周报，每项指标都与上一周对比，生成后自动归档到资料文件夹并在编辑器中打开。
  5. 交互式提问卡片 — Agent 遇到需要确认的问题时会弹出选项卡片，作答后继续执行。
  6. MCP 插件能力增强 — 插件编辑器新增「启动 / 停止」按钮；修复插件工具被白名单过滤导致模型看不到的问题，修复 mcp-admin 停止后无法再启动的问题；新增内置示例插件 demo（echo / now）。
  7. 品牌与「关于」页 — 应用名统一为 CodeDash，设置里新增「关于」页，显示版本号、GitHub 与官网入口。
  8. Agent 引擎随包分发 — agent-core 及其全部原生依赖（代码解析、向量检索、嵌入式数据库、终端）与内置插件一起打包，安装后开箱可用；macOS 版剔除与平台无关的预编译产物，安装包体积减少约 40%。

说明

  1. macOS 安装包未使用 Apple 开发者证书签名（ad-hoc 签名），首次打开需要在「系统设置 → 隐私与安全性」中点击「仍要打开」放行一次，详见 文档 · macOS 首次打开。
  2. Windows 版同步更新到 v0.2.0，包含上述全部新功能；Agent 引擎通过系统 Node.js 启动，使用前需先安装 Node.js。
  3. macOS 版 Agent 引擎改用应用内置运行时启动，无需预装系统 Node.js。
  4. Windows 安装包未做代码签名，首次运行 SmartScreen 可能提示「未知发布者」，选择「仍要运行」即可。
  5. macOS 版语音转文字依赖的 ffi-napi 在 Apple Silicon 上暂无预编译产物，该功能会自动不可用，不影响其余功能。
FIRST RELEASEv0.1.02026-07-27

v0.1.0 首次发布

主要更新

  1. 界面美化 — 整体 UI 重新设计，亮色 / 暗色双模式，视觉风格更加现代统一。
  2. 语音识别 — 集成 Vosk 离线语音引擎，支持离线语音转文字，无需云服务，保护隐私。
  3. 工具增强 — 新增 Workflow 工作流引擎（支持并行 / 串行 / Pipeline / Loop 四种执行模式）；引入工具权限系统（RBAC），精细控制 AI 可调用的工具范围。
  4. ComputerUse 与浏览器工具 — 基于 nut.js 的桌面自动化，AI 可直接控制鼠标键盘；内置 headless Chromium，支持 12+ 浏览器操作工具。
  5. 提示词增强与覆盖 — 增强系统提示词效果，支持用户自定义提示词覆盖默认行为。
  6. 通知功能 — 任务完成、异常等关键节点系统通知。
  7. 交互优化 — 工具默认收缩与展开、历史提问小窗、会话页面移至右侧而非居中、历史提问分页。
  8. Fork / Git 功能 — 内置 Git 操作与项目 Fork 能力。

细节更新

  1. 左侧文件夹默认不打开，且增加记忆（记住用户折叠 / 展开偏好）。
  2. 右键菜单「资源管理器 / 终端打开」位置上移，更方便触达。
  3. 修复 EditFile 写长文本容易出错的问题。
  4. 任意位置右键弹出对话处理窗口，快速发起 AI 交互。
  5. 输入框内容复制优化；输出内容复制按钮位置优化；输入框退出后重新进入保留之前输入内容。
  6. 文件夹内 Ctrl+F 搜索支持。
  7. 工具调用默认不展开，减少视觉干扰。
  8. 添加 CodeDash 品牌图标。
  9. 实现并发能力，多任务可并行执行。
  10. 添加插件模块，支持扩展自定义功能。
  11. 针对 DeepSeek 优化缓存策略，提升响应速度。
  12. 添加英语模式，界面国际化。
  13. 添加 Debug 模式，便于开发者调试。
