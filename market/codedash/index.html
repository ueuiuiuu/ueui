##Features

九项能力，都指向同一件事

从读代码、改代码到跑测试、控浏览器，Agent 需要的能力都做进同一个进程里。

自研 Agent 引擎
零框架依赖的 agent-core，think → act → stream 循环；Plan、Agent、Chain 三种模式共用一套工具协议。
深度代码理解
tree-sitter 解析 + bge-small-zh 语义嵌入，BM25 与向量双层召回，索引可完全离线。
浏览器自动化
内置 Chromium 控制器，导航、点击、输入、滚动、截图等 12+ 操作，AI 像人一样用网页。
计算机控制
基于 @nut-tree/nut-js 驱动鼠标、键盘与屏幕，桌面也被 Agent 接管。
双进程架构
Electron 前端与 Agent 后端以 JSON-RPC 2.0 over stdio 通信，一方崩溃不影响另一方。
三层记忆
任务摘要 + 轮次向量索引 + RRF 融合召回，长会话不丢上下文。
自动化调度
一次性、每日、每周、自定义间隔四种触发，定时执行 AI 任务。
离线语音
集成 Vosk 引擎，语音转文字在本机完成，不上传云端。
工作流编排
并行、串行、Pipeline、Loop 四种执行模式，复杂任务一键编排。
##Architecture

前端与引擎，各自独立

界面是界面，引擎是引擎。两者只通过一条 JSON-RPC 2.0 管道说话，所以引擎可以单独升级、单独调试，也可以被别的客户端复用。

  • stdio 双向通信，没有本地端口，也不暴露网络面
  • 崩溃隔离：引擎挂了界面还能给出错误，反之亦然
  • 可替换前端：同一套 agent-core 可以接 CLI 或别的壳

##Modes

三种工作模式

从安全只读，到全权执行，再到自动队列——按任务的危险程度选。

PLAN

只读探路

AI 只用只读工具探索仓库，把结论写进 .plan.md。你确认之后，再切到 Agent 执行。

只读安全
AGENT

全权执行

可读写文件、执行 Shell、控制浏览器和计算机。适合已经想清楚、只等落地的任务。

完整权限
CHAIN

自动队列

Plan → Agent → Plan → Agent 自动循环，直到队列清空。适合一次交代一串活儿。

无人值守
